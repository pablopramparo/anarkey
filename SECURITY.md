# Security policy

## Reporting a vulnerability

Please report security problems privately and not in a public issue. Use GitHub's private reporting:
open the **Security** tab of the repository and choose **Report a vulnerability**. If that option is not
available, open an issue that only says you have a security report, without any detail, and a maintainer
will arrange a private channel.

Include what you found, how to reproduce it, the app version (Settings → Credits, in Spanish
Ajustes → Créditos) and the Android version and device.

This is a volunteer project, so replies are best effort. You will get an acknowledgement as soon as
possible, and the fix will be credited to you if you want, once it is released.

## What matters most here

Anarkey promises that microphone audio stays on the device, that the app has no Internet permission and
that recordings and songs are the person's own data. Reports about any of these are the highest priority:

- audio or recordings leaving the device, or being readable by other apps;
- the app gaining a network permission or sending data anywhere;
- loss of recordings or songs caused by an update or a migration;
- the signing key, passwords or personal data appearing in the repository.

## Supported versions

Only the latest release is supported.
